## Авторизация

**Ссылка на страницу**: [https://spark-it.site/login](https://spark-it.site/login)

Позитивные кейсы:

* При вводе зарегистрированного логина и соответствующего ему пароля запрос на авторизацию происходит успешно
* При нажатии на кнопку скрыть/показать пароль в состоянии, когда пароль показывается, пароль отображается в виде точек и иконка кнопки меняется на открытый глаз
* При нажатии на кнопку скрыть/показать пароль в состоянии, когда пароль скрыт, пароль показывается в исходном виде и иконка кнопки меняется на перечеркнутый глаз
* При нажатии на ссылку "Зарегистрируйтесь" происходит переход на страницу регистрации

Негативные кейсы:

* При вводе зарегистрированного логина и несоответствующего ему пароля на запрос авторизации появляется сообщение "Неправильный логин или пароль"
> БАГ. Не появляется уведомление с сообщением "Ошибка при авторизации. Попробуйте еще раз."

> БАГ. Не появляется уведомление с сообщением "Ошибка при авторизации. Попробуйте еще раз."
* При попытке отправить запрос на авторизацию с незаполненным инпутом логина появляется сообщение "Введите логин" и уведомление с соощением "Ошибка при авторизации. Попробуйте еще раз."
* При попытке отправить запрос на авторизацию с незаполненным инпутом пароля появляется сообщение "Введите пароль" и уведомление с соощением "Ошибка при авторизации. Попробуйте еще раз."

## Навигация

Позитивные кейсы:

* Логотип сервиса отображается неавторизованному пользователю
* Для неавторизованного пользователя отображаются только кнопки "Войти" и "Зарегистрироваться"
* При нажатии на кнопку "Войти" происходит переход на страницу авторизации
* При нажатии на кнопку "Зарегистрироваться" происходит переход на страницу регистрации
* При нажатии неавторизованным пользователем на логотип сервиса происходит переход на страницу авторизации
* Для авторизованного пользователя отображаются кнопки "Главная", "Мэтчи", "Чаты", "Магазин", "Профиль", "Выйти из аккаунта" и аватарка профиля
* Логотип сервиса отображается авторизованному пользователю
* При нажатии авторизованным пользователем на логотип сервиса происходит переход на страницу с анкетами пользователей (на главную страницу)
* При нажатии на кнопку "Главная" происходит переход на главную страницу (страницу с анкетами пользователей)
* При нажатии на кнопку "Мэтчи" происходит переход на страницу мэтчей
* При нажатии на кнопку "Чаты" происходит переход на страницу чатов
* При нажатии на кнопку "Магазин" происходит переход на страницу магазина
* При нажатии на кнопку "Профиль" происходит переход на страницу профиля
* При нажатии на кнопку "Выход из аккаунта" происходит выход из аккаунта и переход на страницу авторизации
* При нажатии на аватарку профиля происходит переход на страницу профиля пользователя
* При наведении на аватарку профиля показывается текущий баланс пользователя, количество бесплатных и платных реакций

## Главная страница (анкеты других пользователей)

**Ссылка на страницу**: [https://spark-it.site/feed](https://spark-it.site/feed)

Позитивные кейсы:

* При нажатии на кнопку "лайк" карточка пользователя свайпается вправо
* При нажатии на кнопку "дизлайк" карточка пользователя свайпается влево
* При наведении на фотографию на карточке пользователя отображаются кнопки "листать назад" и "листать вперед"
* При нажатии на кнопку "листать назад" отображается предыдущая фотография пользователя
* При нажатии на кнопку "листать вперед" отображается следующая фотография пользователя
* При захвате карточки пользователя и отпускании ее в правой части экрана происходит свайп вправо
* При захвате карточки пользователя и отпускании ее в левой части экрана происходит свайп влево
* При нажатии на кнопку "пожаловаться" открывается окно для жалобы

Негативные кейсы:

* При захвате карточки пользователя и отпускании ее в верхней центральной части экрана происходит возвращение карточки на изначальное место (на центр экрана)
* При захвате карточки пользователя и отпускании ее в нижней центральной части экрана происходит возвращение карточки на изначальное место (на центр экрана)
